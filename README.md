# 🌐 Portfólio Pessoal — Julio Medina

> Portfólio pessoal desenvolvido com foco em **organização, responsividade e integração real entre frontend e backend**.

🔗 **Deploy:** [https://medina-portfolio-six.vercel.app](https://developer-medina-portfolio.vercel.app/)

---

## 📌 Sobre o projeto

Este repositório contém o código-fonte do meu **portfólio pessoal**, pensado não apenas como uma vitrine visual, mas como um projeto técnico real, voltado para boas práticas de desenvolvimento frontend.

A aplicação consome dados de uma **API backend própria** para renderizar os projetos de forma dinâmica, simulando um cenário real de produção. O foco está em clareza de código, separação de responsabilidades e experiência do usuário.

---

## 🛠️ Tecnologias utilizadas

### Frontend

* **HTML5 semântico**
* **CSS3 moderno**
  * Mobile First
  * Flexbox e Grid Layout
  * Animações e transições suaves
  * Skeleton Loading
 
* **JavaScript (ES6+)**
  * Manipulação de DOM
  * Controle de estado visual
  * Consumo de API via `fetch`
  * Efeito de digitação (typewriter)

### Backend (consumido pelo frontend)

* **API REST própria**
* Comunicação via HTTP
* Dados dinâmicos para renderização dos projetos

---

## ⚙️ Funcionalidades

* Renderização dinâmica de projetos
* Skeleton loading durante o carregamento dos dados
* Cards de projetos gerados programaticamente
* Layout totalmente responsivo (mobile, tablet e desktop)
* Animações sutis focadas em experiência do usuário
* Menu responsivo com controle de estado via CSS + JavaScript
* Efeito de digitação na Hero Section
